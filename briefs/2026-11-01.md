## Regressions and risks

**Invariant 1 — mentor session is the dearest thing: HOLDS.** `MENTOR_CENTS` 2900 >
dearest product 2000 (bundle). The import-time throw at `src/lib/products.ts:114` would
have failed the Vercel build otherwise.

**Invariant 2 — bundle costs more than either product it contains: HOLDS, but by $2.**
Bundle $20 > careers $18 and > CV $5. The margin narrowed when the CV dropped to $5
(`5ac5d4c`) and is now the thinnest it has been. Unlike rule 1, **rule 2 is not enforced in
code** — there is no import-time assert for it, so a future careers price above $20 would
ship silently and make the careers report strictly dominated. Worth adding the same throw.

**Paywall slicing — HOLDS in all three routes.** Every prompt asks for the full ranked
answer ("Give the FULL review — every fix worth making", and for careers "ORDERED
BEST-FIT FIRST… This ordering is load-bearing"), and every route slices server-side from
the **end**: `essay/route.ts:149` `allTips.slice(-FREE_TIPS)` with `FREE_TIPS = 3`, `cv/route.ts:149` the same with `FREE_TIPS = 2`,
`careers/route.ts:222` `careers.slice(-1)`. No prompt asks the model for less.

**`src/lib/leads.ts` key parsing — intact.** It scans `fledgy:tools:*` and `fledgy:usage:*`
and takes the segment after the last colon. Grepping every `fledgy:` key constructor across
`src/lib/` finds only two families under those prefixes — `fledgy:usage:<tool>:<email>`
(`usage.ts:41`) and `fledgy:tools:<email>` (`leads.ts:22`) — and both end in the email, so
both parse. No key gained or lost a segment this week.

One low-severity inconsistency, pre-existing and not a regression: usage keys use
`normaliseEmail()` (strips `+tags`, strips dots on gmail — `usage.ts:74-86`) while
`toolsKey`/`leadHash`/`seenKey` use plain `trim().toLowerCase()`. For a gmail address with
a dot or a `+tag`, the two key families yield different strings, so one person can appear as
two rows and the `tools` column can read empty for the normalised row. It inflates the lead
list slightly; it does not produce garbage rows.

**No dependency changes.** `git log --since='7 days ago' -p -- package.json
package-lock.json` is empty. The build constraint was respected.
